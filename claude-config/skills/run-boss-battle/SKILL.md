Boss themes: 1 The Refund Incident, 2 The Narrow Coordinator, 3 The Missing Teammate, 4 The Context Cliff, 5 The Noisy Reviewer, 6 The 97% Lie.
1. Read that week's tasks from the calendar in `PLAN.md` (section 4).
2. Pull 6 questions from `app/backend/content/questions.yaml` for those tasks; reuse the scenario name to build one connected story.
3. Present one question at a time, collect answers, then run the post-mortem: for each wrong option name the exam trap it represents.
4. Close with the squad's weakest task and one action for next week.

The problem

The exam punishes "sounds right"

5 domains, 6 scenarios, scenario-based multiple choice. Wrong options look like good engineering.

Rules the exam keeps testing

  • Enforce high-stakes rules in code (gates, hooks), not in the prompt
  • End the loop on stop_reason, never by parsing text
  • Fix tool descriptions before adding a classifier
  • Subagents have isolated context: pass what they need
  • Explicit criteria beat "be conservative"
  • Sync API for blocking work, Batch for latency-tolerant

CCCA Academy7
Learn · Practise

Practice is weak-first, so trust it

You don't choose what to revise. The engine does, from your own answers.

Use it well

  • Answer with keys 1-4 or A-D: fast drills
  • Read the reason for every option, not just the right one. That is distractor training.
  • Stuck on a concept? Explain with AI gives a worked example grounded in that task.
  • Mastered = your latest answer to each of the task's questions is correct. A later miss un-masters it.
  • Use My mistakes before every mock exam.
  • Generate fresh AI questions once the bank feels familiar.
CCCA Academy8
Practise · Mock exam

A real dress rehearsal

60 questions · 90 minutes · pass 700/1000 · no Ask AI · results only at the end.

When to sit it

  • Week 0: once, as your baseline
  • Week 7: after every Learning path stop is passed
  • Read the "What to learn next" plan it gives you, then drill My mistakes
  • XP is paid only for beating your best score, so re-sitting to farm XP does nothing
  • Target 800+ here before booking the real exam (real pass mark is higher than 700)

Short exercises that feel like the exam

  • Write a system prompt and tool definitions (JSON) for a scenario
  • Scored per rubric criterion, each with a fix note

Progress · XP, levels, readiness

Readiness is the number that matters

How you earn

First correct answer to a question10 XP
Repeat correct answer2 XP
Milestone pass (70+)120-220 XP
Mock exam (on improvement only)up to 200 XP

Readiness = your mastery weighted by each domain's exam share. Aim for 80%.

Badges: First Step, D1-D5 Specialist, Loop Master, Gatekeeper, Isolation Expert, Batch Boss, Builder of All.

Squads rank by average XP: lifting your weakest teammate helps most.

CCCA Academy13
Use it efficiently

8 habits that get you ready fastest

1 · Follow the path

Learning path → "you are here". Don't tab-hop.

2 · Weakest first

Dashboard lists your weakest tasks. Click one and drill it.

3 · Read every option

Why the wrong options are wrong is the exam skill.

4 · Wrong → trap

Follow the link back to the task's traps before retrying.

5 · 15 min daily

Short daily drills beat one long weekly cram.

6 · Attempt first

Plan → guide → fix notes. Reference solution last.

7 · Break things

Turn sandbox guards off. Watching the failure makes it stick.

8 · Mistakes before mock

Clear "My mistakes", then sit the mock. Target 800+.

Questions you'll get

FAQ

Do I need an API key?Only for Tutor, Ask AI, AI question generation and reviews. Curriculum, Practice, Mock exam, Progress and the sandbox demo work without one.
Is my key safe?It stays in this browser tab's session, travels per request and is never stored or logged by the server. Closing the tab clears it.
Where's my progress saved?On the server, keyed by your name. Use the exact same name on every device.
Can I change track later?Yes, in Settings. Your history stays; only the question levels you see change.
Are these the real exam questions?No. All 150 are original and written to train the same reasoning. Never add real exam items.
Why did a task lose "mastered"?Mastery means your latest answer to each question is correct. One new miss un-masters it, by design.
Why no XP for my resubmission?XP pays only for beating your best score, and not after you've opened the reference solution.
App pass mark is 700. Is that the real one?The plan targets 720 for the real exam. Aim for 800+ in the mock.
DIAL "Test connection" fails?Connect to EPAM VPN and check the model name via /openai/models.
Can I add questions?Yes, via PR to content/questions.yaml: 4 options, one correct letter, a reason for each option.

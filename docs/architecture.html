CCA Academy: Architecture

Repo-based, CI-verified gamification for the Claude Certified Architect (Foundations) programme.

Data flow

  1. Participant studies the weekly brief, builds the upstream lab locally (their own API key), and runs cca quiz.
  2. CLI writes a results file and pushes a PR to the private repo.
  3. grade.yml verifies quiz answers against protected keys and runs autograder checks on lab artefacts.
  4. xp-engine awards XP, levels, badges and squad streaks; leaderboard.yml regenerates LEADERBOARD.md.
  5. Friday digest posts team standings and weakest domains to Slack.

# ADR-003: Learn -> Build -> Break -> Quiz -> Boss weekly loop

**Status:** Accepted

## Context
The exam is scenario-based with plausible distractors. Reading alone does not build the judgement tested. Hands-on experience is flagged as critical for Domain 3 especially.

## Decision
Every week combines a lab (build), a deliberate anti-pattern challenge (break), daily drills, and a Friday scenario boss battle with distractor post-mortems.

## Consequences
+ Trains elimination reasoning and retention (spaced daily drills). - ~3.5 hrs/week budget is tight; the Break step is cut first if time is short.
